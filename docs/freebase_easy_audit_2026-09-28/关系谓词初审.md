# Freebase Easy 人物关系谓词初审（2026-09-28）

输入：同目录的 `predicate_inventory.tsv`（全库 1,919 个谓词）、`person_pair_samples.json`（163 个两端名称匹配 `Person` 的谓词，每个最多 5 条随机样例），以及第二轮 `review_samples.json`（20 个候选谓词合计 441 条样例）。计数表示**名称匹配事实数**，不表示真实人物社会关系数。以下是首轮人工分类，尚未冻结白名单。

## 1. 可直接进入下一轮覆盖审计的候选

| Freebase Easy 谓词 | 名称匹配事实 | 初步语义与方向 | 现有关系的概念参照 | 待核查点 |
| --- | ---: | --- | --- | --- |

| `Spouse (or domestic partner)` | 302,788 | 双向配偶或伴侣 | `spouse`、`unmarried_partner` | 原始谓词不能可靠拆分婚姻与非婚伴侣 |
| `Influenced By` | 23,430 | 主体受客体影响 | `influenced_by` | 影响未必发生在两人相识时；不能当直接交往 |
| `Academic advisor` | 5,816 | 样例呈学生 → 导师 | `student_of`、`doctoral_advisor` | 导师关系口径和方向需更多样例 |

## 3. 明显不能按“直接人物社会关系”使用的高频谓词

| 谓词 | 名称匹配事实 | 样例反映的问题 |
| --- | ---: | --- |
| `is-a` | 365,307 | 客体多为职业或类型名称，如 `Musician` |
| `Profession` | 208,576 | 客体为职业值，如 `Musician`；名称恰好也在 `Person` 候选中 |
| `kg/object_profile/prominent_type` | 80,363 | 客体为显著类型，而非另一个人物 |
| `Member of` | 11,914 | 客体常为乐队/团体；可留待“共享组织”中介分析，不直接造人际边 |
| `Film crewed` | 11,387 | 客体是 `Makeup Artist` 等工种 |
| `Leader of` | 7,690 | 随机样例为人物自指，不能视为领导关系 |
| `Place of birth` / `Place of death` | 3,410 / 888 | 地点名称与 `Person` 名称碰撞 |
| `Employment history` | 1,049 | 客体多为大学等机构；不能无时间信息直接构造同事关系 |
| `Person` | 1,441 | 样例主体是 `Boston` 等地点，客体才是人物 |
| `Named after` | 492 | 命名纪念不是亲属、合作或直接社会联系 |
| `Family` / `Royal line` | 203 / 17 | 客体是家族/王朝，不是另一名人物 |
| `Record Label` | 612 | 客体是唱片公司 |
| `Organization founded` | 181 | 客体是机构 |
| `Married To` / `Parent` | 8 / 2 | 第二、三阶段样例以虚构人物或明显错误配对为主 |

其他低频名称匹配也不能自动进入图；完整证据保存在同目录的两份原始输出中。职业、学校、机构、作品和事件可以用于属性或后续中介分析，但必须与**原生人物—人物边**分开报告。

## 4. 第二轮全量覆盖与样例复核

`scripts/freebase_easy_all_relation_coverage.py` 完整扫描 362,243,831 条事实，无解析错误，逐谓词人物对计数与上轮清单一致。以下均为**不同候选名称的人数**，同一人参与多个谓词只计一次；出生/死亡列仅表示存在原始事实，并未解析日期。

| 候选集合 | 参与人物 | 有 `Profession` | 有出生或死亡事实 | 同时有职业和生卒事实 |
| --- | ---: | ---: | ---: | ---: |
| v1 优先 11 类 | 641,325 | 228,581 | 301,812 | 178,308 |
| v1 待复核 9 类 | 1,762 | 1,209 | 1,307 | 1,105 |
| 全部 163 类名称匹配 | 988,927 | 408,182 | 407,020 | 249,713 |

`全部 163 类` 混有职业、类型、地名、团体和作品等名称碰撞，不可作为社会关系图规模。v1 优先集合也仍未经实体标识、边语义和人物真伪核查。尤其 **178,308 只是原始属性同时存在的探索上界，不是最终可训练节点数**；缺职业的人可作为无标签邻居，缺生卒年的人可参与非时期图，因此也不应把这一交集当成整张图的节点数。

第二轮样例加强了 `Academic advisor`、`Martial Art Instructor(s)` 的师生/训练方向判断，`Influenced By` 主要表示知识或艺术影响，不能等同当面交往。`Matches Lost` 是比赛对手，`Demonstration medal won` 可能由赛事中介扁平化，`Episode segment` 和 `Group` 也混有作品或团体语义，继续暂缓。`President` 可作为**副总统任职于某总统期间**的候选边另行复核，但 v1 配置及上述 v1 计数保持不变，避免修改分类后混用旧统计。两条哲学影响谓词的样例呈互逆方向，尚需用全部成对事实验证。

子集全量结构审计现已证实：两条哲学影响谓词的 **250 对记录完全互逆**，后续映射为影响关系时应保留来源并避免重复计边；它们与通用 `Influenced By` 另有 53 对重合。`President` 全部 49 条均呈美国副总统→任职期间总统，可从“语义不明”提升为“范围明确、待身份核验”的关系候选。名人恋爱与配偶谓词有 390 条同向记录重合，两者不能直接当互斥类别。完整回传报告见 `pair_subset_audit_report.txt`。

## 5. 下一轮要回答的问题

1. `scripts/freebase_easy_export_person_pairs.py` 先将全部两端名称命中 `Person` 候选的原始事实导出，保留所有谓词和源文件行号，**不按职业、生卒年或 v1 关系层级筛选**。预计与上轮 1,728,197 条名称匹配事实核对；输出是待清洗候选记录，不是真实人物社会关系表。
2. `freebase-links.txt` 的已见格式为 `:d:<数字>:<名称>\tfreebase-entity\t<http://rdf.freebase.com/ns/m....>\t.`。核查名称键与原始 Freebase 标识的覆盖、一对多和多对一情况，不能假设去掉前缀后名称唯一。
3. 对重点谓词核查方向、对称性、重复陈述和跨谓词重叠；将 `President` 的 49 条事实全部人工复核。先冻结 Freebase 自身的关系白名单，再做与旧 40 类的映射。
4. 对选中关系输出筛选漏斗：`Person` 候选 → 参与关系 → 有职业 → 有可解析生卒年。缺职业的人可按现有图协议保留为无标签邻居；日期缺失者不自动从普通图中删除。

# CBDB 职业填充方案与覆盖探查（2026-10-03）

已阅读 `CBDB_HANDOFF.md`、职业审计、扁平表规则及项目共同数据协议，并直接以只读方式查询 2026-09-14 SQLite。未修改原库、v1 白名单或 v1 三元组。本文提出下一阶段方案，不冻结新的职业口径。

## 判断

应先建立可追溯的职业证据，再形成单标签。职业缺失、职业多值与类别失衡是三个问题，不能靠统一优先级同时解决。继续保留“做官”这个单层宽类，不需要恢复官位排序或职业层级。

“合适”的标签至少应满足：原始材料明确描述本人从事的职业或活动；没有把亲属、品行、资格、财富、技能误写成职业；多人同名时人物对应可靠；标签抽取不依赖之后用于预测的关系边；选择规则在看模型结果之前固定。诗人、学者等是否纳入，要明确目标是宽泛职业/活动领域还是严格的谋生职业；状态码通常不能证明本人以该活动谋生或其为一生主业。

## 重算结果

所有职业结果仍依赖尚未逐码审核的 v1 白名单，不能解释为真值。

日期合格人物 93,688 人，v1 有职业 38,789 人，缺职业 54,899 人。缺职业者中 52,726 人没有任何 STATUS_DATA，只有 2,173 人有状态记录。保持现有任官入口不变时，即使把这 2,173 人全部补上，状态表扩充最多增加这么多人，且其中许多人只有非职业身份。因此审核状态码是必要的质量工作，但不能指望它填满 5 万多人的职业。

v1 日期合格“做官”人物中，2,928 人另有至少一个非官职业候选；最终图中对应 2,306 人。日期合格人物中共 696 人有多个不同的非官候选类。这里是当前宽类之间的冲突，不能把同属“写作”的诗人和词人重复算作跨类冲突。

保持 v1 日期及直接关系规则、仅放宽职业要求的辅助图有 43,740 个端点、143,528 条去重三元组，其中 24,912 个端点能按 v1 标注，18,828 个没有标签。它可以评估保留无标签邻居的潜力，但不替代已约定的“双端都有职业”交付表，也不是新增职业证据。

## 建议的填充顺序

### 1. 审核有限的码表，保留全部证据

已导出 270 个实际出现状态码到 `status_inventory.tsv`，包含中英文名、官方类别、原始行数、独立人数、日期合格人数、任官重叠、v1 图中人数、v1 映射、三条带 source/pages/notes 的原始样例。所有 `review_decision` 均为“待审核”，不是自动批准。

逐码标记职业可用、非职业、有歧义，并填写理由。既查现有 92 码的边界，也查漏项：比丘尼、翻译、教育家、出版家及若干戏曲写作相关码等可进入复核；卜筮者、风水师、义军首领需讨论类别边界，不能未经复核硬塞进宗教、学术或从军。不能把“工于文”当作“诗人”，或把“博学之人”当作“学者”。官方类别只供参考。

每个人先存证据集合：person_id、候选宽类、原表和记录定位字段、原码、source_id、pages、证据摘录、审核状态、规则版本。再另存最终 occupation、decision_reason、冲突状态。最终仍可只给一个职业，但不删除其余候选事实。

### 2. 复核实际任职边界，避免过严过滤

原库 `c_assume_office_code` 明确区分赴任、辞不就、未赴任而卒、未赴任而改命、未赴任。日期合格且有正官职 ID 的 36,346 人中，至少一条明确赴任的有 2,756 人，所有记录均为“未详”的有 33,459 人，所有记录均明确未任的有 16 人。

因此可以先排查明确未任的记录，再查虚衔、追赠、爵位和备注；不能要求每个人都填写“赴任”才承认其官职。一个人有未任记录和其他任职记录时，也不能整个人一票否决。16 人不是全部虚衔或错误任官的规模，码表尚未完成全面审核。

现有白名单还将武将、武官归“做官”，軍卒、牙將归“从军”，医官归“做官”、行医归“医疗”。这可以是一种规则，但应统一解释其分类轴，避免无意混用任职性质与活动领域。

### 3. 从人物自身材料补缺，模型只提出有证据的候选

缺职业者中 38,135 人 BIOG_MAIN.c_notes 非空，54,860 人有 BIOG_SOURCE_DATA 来源关联，1,833 人有 BIOG_TEXT_DATA 文献角色记录。它们是审核入口，不能算作已补职业人数。备注样例既有明确描述“teachers”的内容，也有仅列出处或谈妻子、家谱的内容；有来源链接不代表本地已有传记全文。

优先检查日期合格且已有关系的人物，再检查备注中是否存在明确职业陈述。可让语言模型从给定文本提取“人物、职业候选、原文证据、否定/未任信息”，并允许无证据输出；它不应根据姓名、名气、亲属职业或交往行为猜职业。抽取流程先人工审核一小批，检查本人指向、技能与职业混淆、否定表述，确认有效后再扩大。

BIOG_TEXT_DATA 可提供撰著、编辑、编纂、出版、翻译等活动证据，但参与一部著作不自动证明终身职业。尤其不能因为“给别人写墓志/赠诗”的 ASSOC 边就补成作家，再把同一边送入职业预测模型。

若内部材料仍不足，可另建带出处的外部补充队列。人物匹配需要姓名及可用生卒、籍贯、字号等多项证据；同名或年代矛盾者不自动合并。外部标签与原生 CBDB 标签分开报告，以便控制补全引入的名人选择偏差和跨来源人物重合。

### 4. 冻结单标签政策，再判断研究是否可行

交接文档已约定官类优先。主版本先保留该口径：有通过边界复核的官类证据者标做官；无官类且唯一非官宽类者标该类；没有可靠证据或多个非官类者标为未决。若要改为“代表活动领域”，需要显式更改目标定义，不能悄悄以非官优先提高多样性。频次、码序、最长任职和模型预测不能自动替代主业证据。

冻结后按全库、日期合格人物、关系端点、最终双端合格图及时期分别重算人数、缺失、冲突、关系数和类别分布。可另存无标签邻居辅助图，但未知人物不进入监督和指标，也不能成为“未知职业”训练类别。

v1 最终图经商只有 7 人、务农 13 人、医疗 25 人。重采样或加权不能制造新的独立监督证据。是否开展多职业任务，应根据补全后的各类独立人物和各时期/数据划分的覆盖判断；若仍不足，就缩小到有证据支持的比较，或将 CBDB 用作限定任务/描述性对照。

基线重算与 v1 summary 的人数、各类人数和边数一致；状态清单是 270 个码、73,469 原始行。未完成全部码的人工语义审核、所有任官记录的性质审核或任何外部人物补全，因此本文不声称生成最终职业真值。

# Freebase decadal shared GraphMasks, 1900–2000

Question: does locally shared explanation over adjacent yearly life-window graphs give stable within-decade relation shares, while allowing explanation rules to differ across decades? No global-century GraphMask is trained.

Ten disjoint groups cover all101 centers exactly once: 1900–1909,1910–1919,...,1980–1989,1990–2000. The last contains11 windows by explicit design. Each yearly graph still uses ±20 life membership, original alive2026 policy, L1-only inputs/target and its own frozen RGCN42. Group1900–1909 reuses the completed order42/per_window_batch_v1 experiment with exact configuration match; nine new probes are trained. No graph data, RGCN weights or previous reports are overwritten.

Each group independently initializes GraphMask42, shuffles every round with order42, and uses independent keyed per-window/batch RNG; validation100042/report42. Each epoch uses the minimum number of full32-root batches in that group. Six joint epochs, three per layer; budgets therefore differ in total batch updates as group sizes differ, and actual steps_per_window is recorded. All gates and replacement baselines are shared only within a group. Independent per-window dual variables; KLbeta0.03, AdamLR1e-4, dualLR.01. Any-stage selection prefers all-window <=5% relative validation F1 drop, otherwise all-window <=10%, then minimizes equally weighted mean hard retention. Report disabled Layer0 gates explicitly. No extra smoothness objective or selection.

Run `python -u Freebase/run_decadal_shared_graphmask.py` in persistent tmux with the wywikidata interpreter. It preflights101 source/checkpoint paths and protocols, locks the matrix, checks existing results, and dispatches <=4 child jobs to candidates0/1/3/4/5 only if free>=8000MiB and utilization<60%. Each child has its own lock, persistent log, epoch checkpoints, manifest and exit status. GPU2 is excluded. Interrupted matrix invocations refuse active child locks, reuse completed compatible groups and resume compatible epoch states; do not invoke while existing children run. Failed no-feasible-checkpoint groups remain failed; no threshold is silently relaxed.

Matrix root: runs_graphmask/freebase_decadal_shared_graphmask_1900_2000_rgcn42_gm42_order42_v1. Complete summary requires101 test reports and505 Layer0 group rows; output matrix_summary.tsv and relation_group_summary.tsv. After training, `--summarize-only` safely regenerates summaries. Per-group roots are in the matrix config; source/control code revision, launch commands, GPU snapshot, time, status and paths are recorded. Group1900 is a cached result with its original provenance revision.

Interpretation: plot raw annual shares, fidelity and keep rates; mark group boundaries. Across-group jumps can include explainer differences, so they are not automatically social-historical transitions. Cross-boundary overlapping ten-window groups remain a future diagnostic, not part of this authorized run. No new seed repeats yet.

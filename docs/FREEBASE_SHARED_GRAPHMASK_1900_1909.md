# Freebase shared GraphMask pilot

Research question: can one shared message gate explain the ten independently trained, frozen RGCN seed42 models for centers 1900–1909 while preserving each model's predictions?

Data and controls: reuse v4 L1-only artifacts, five relation groups, ±20 life windows, existing split20260814; no RGCN retraining or source data changes. Existing independent GraphMask42 reports are the descriptive comparator. Because the models are fixed, no new shared-model split is created. This is an in-range explanation experiment, not an unseen-person or future-year generalization claim.

One GraphMask (including replacement vectors) is shared. A single Adam optimizer updates it. Ten independently constrained positive dual variables use RMSprop. Models and reference models are frozen. Each epoch cycles through all windows, using the minimum number of full 32-root batches available across windows; shuffled roots rotate each epoch. This equalizes window update counts; no temporal loss, year feature, model-specific projection, or adapters are introduced. Model-specific hidden representations may differ; compatibility checks verify dimensions but do not assert semantic alignment.

Budget: seed42; two layers, reverse layer activation, three joint epochs per layer (six total). LR0.0001, dualLR0.01, KL beta0.03 (unchanged); validation sampler100042 and report sampler42. The validation F1 bound is one-sided relative **drop**, not the legacy absolute relative difference (F1 improvements are accepted). Prefer any-stage common checkpoints satisfying <=5% drop in all windows, then <=10%; within a tier minimize equally weighted mean hard retention over windows/layers. No curve-smoothness selection. Layer0-disabled selections remain valid and marked. No feasible common checkpoint is a failed pilot, not replaced by a fabricated success. Sparse-degree or pooled fidelity cannot substitute for per-window bounds.

Train-only roots update probe weights; validation selects the shared checkpoint; test reports are generated afterward. Reports use identical gate/baseline weights in per-window source-validated native envelopes. Native provenance hashes are preserved; no extra large-file hashing audit.

Run: `bash Freebase/run_shared_graphmask_1900_1909.sh --preflight-only`; then same without preflight in persistent tmux after checking GPU/space/processes. Use CUDA_VISIBLE_DEVICES to select one physical GPU (ten small frozen models reside together). `--resume` restores epoch-boundary probe, optimizer, duals, and best checkpoint; each epoch reseeds explicitly. A lock prevents concurrent launches; normal launches refuse existing manifests. Logs, manifest, exit status and last state remain in `runs_graphmask/freebase_shared_graphmask_1900_1909_rgcn42_v1`. Code Git revision and source paths are recorded. Test masks and relation statistics in each `center_YEAR/test_report`.

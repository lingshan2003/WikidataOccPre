# 本轮 L1 审核协议

用户要求审核上轮 `cross_l1_conflict` 和 `unmatched` 两类，优先确定 L1，不裁决 L2/L3。固定输入为 943 个已选职业词、1,710 个原图人物；已有唯一 L1 查表候选的 1,474 个词不在本轮逐项语义审核范围内。

三个独立批次使用 GPT-6 Luna、xhigh，实际读取每项完整职业、原 URI、候选分类和人物例子后写逐项判断。批次按原词表顺序交错分配，315/314/314 行，原始输入和原始审核表全部保留。主代理核对跨 L1 冲突、高频项、作者近义词锚点和已有 Freebase 同词；第二批审核者另做一次只读一致性审计。主代理的 16 项裁决独立保存在 `primary_adjudications.tsv`，不覆盖批次原始结果。

允许的 L1 为 `Culture`、`Discovery/Science`、`Leadership`、`Sports/Games`、`Other`。这些是 BHHT 大类标签，具体边界优先参考作者职业锚点及已有明确的实验操作口径：

- 科研、学术和相应专业技术/医疗职业归 Discovery/Science；明确司法、军政、宗教权威或组织治理职务归 Leadership。
- 专门文化创作、传播、表演及其制作业务归 Culture。媒体报道体育/政治/科学，仍按报道、写作或主持职责判断。
- 武术家与竞技运动职业归 Sports/Games。主审把 `dbo:SportsManager` 的专门体育队伍管理也纳入该类，沿用 Freebase 棒球队管理口径；该条为中等置信度分组提案，不是假称作者精确同词分类。
- `Other` 是正式职业类，不是缺失兜底。明确普通工种、服务、商业小工种、家庭身份和作者相应负面声名身份可以进入 Other。
- `celebrity` 表示知名度，不自动把厨师变成媒体主持人。政治领导配偶的礼仪/家庭身份，沿用已有 Freebase First Lady of Chile 的 Other 操作口径；该语义提案区别于作者 `first_lady` 的关键词分类。
- 职业字段中的专业活动或学科，可以在含义充分时给中等置信度活动到职业角色的 L1 推断。废奴、参政权及女性主义项用作者 abolitionist/suffragist/feminist 锚点及当前人物例子判断，地理后缀本身不改变大类。
- 学校、公司、组织、人名、地点、残缺短语和真实跨域并列职业，若没有个人岗位信息，保留 `needs_context`，不凭机构名猜员工岗位。

`resolved` 只表示 LLM 给出了单一 L1 建议，需合法标签、high/medium 和单一候选数组；`needs_context` 留空 L1、low，可保留多个可能类别。每项必须有具体理由与证据字段。未检索的语义推理标为 `semantic_reasoning_only`，作者规则和旧 Freebase 表作为本地参照；少数罕见称谓查证后的直接来源链接保留在相应批次行中。主代理的外部检索有一次连接失败，相关主审判断使用明确记录的本地锚点/既有 Freebase 表和语义推理，不声称获得了未返回的网页证据。

校验逐批及总范围的 rank/职业原词/图内人数、唯一键、完整性、合法标签、状态、候选数组、置信度、原因、证据及审核者。主审只可裁决本轮固定943项。原始职业选择、输入图、数据划分、模型结果和训练标签均不修改；本轮没有人工逐项批准，也不把其他未审查词标成已完成 LLM 审查。

复现合并：先运行 `python DBpedia/match_bhht_occupations.py` 重建确定性查表，再运行 `python DBpedia/merge_bhht_l1_review.py` 读取保存的逐项审核与主审裁决。重建的是已保存的结果合并，不是重新调用 LLM。
